Email signature.

Fill in your details, check the preview, then copy the signature into your email app. The logo is animated: fresh air flows through the house and clears it.

Outlook (new Outlook, Outlook on the web, Microsoft 365)

  1. Settings → Accounts → Signatures (on the web: Settings → Mail → Compose and reply).
  2. Create a new signature, click in the box and paste (Ctrl+V). Save, and choose it as the default.

Outlook for Windows (classic)

  1. File → Options → Mail → Signatures → New.
  2. Paste into the edit box, then Save. Some older versions show the first frame only, which is the logo as normal.

Fonts

  1. The signature is set in the brand fonts: Archivo, IBM Plex Mono and IBM Plex Sans. Install them from the brand asset pack (03-fonts) so your own emails show them.
  2. Recipients without the fonts see the brand book's fallbacks, Arial and Consolas, so the signature always looks clean.

Gmail

  1. Settings → See all settings → General → Signature → Create new.
  2. Paste into the box, then Save Changes at the bottom of the page.
